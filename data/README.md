# data/

Word lists and pre-generated boards. **Word lists are not committed**; download them with the commands below (URLs verified 2026-09-12).

## enable1 (validity dictionary)

~173k words. The solver uses 3-8 letter words only.

```sh
curl -sL -o data/enable1.txt \
  https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt
wc -l data/enable1.txt   # 172823
```

## Common words, ~30k (scoring weight / "common" set)

Frequency-ordered list of 30k words (most common first), so line number is a usable rank. Source lines carry trailing tabs; the pipeline strips them.

```sh
curl -sL https://raw.githubusercontent.com/arstgit/high-frequency-vocabulary/master/30k.txt \
  | tr -d '\r\t' | awk 'NF' > data/common-30k.txt
wc -l data/common-30k.txt   # 30000
```

Alternative if that repo goes away: Norvig's Google-ngram counts (333k words with frequencies; take the top 30k).

```sh
curl -sL https://norvig.com/ngrams/count_1w.txt | head -n 30000 | cut -f1 > data/common-30k.txt
```

Either way, intersect with enable1 at load time; both lists contain non-dictionary tokens.

## boards.json

8-10 pre-generated seeds known to contain long words (generated by `wordhunt/board.py` once the solver exists). Committed.
